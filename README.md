# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 通风对照

检查员可把一条本机班测与另一条按主键引入的参照班测钉成通风前后对照（顶栏入口 **通风对照**）。钉定时填写通风间隔分钟，服务端计算浓度差（绝对值），并把两笔浓度、状态与差值一并存档。

- 对照页展示两笔班测的浓度、状态、浓度差与通风间隔分钟。
- 对照存档后来源行被改正，重开对照仍显示钉定时的差，并标 **来源已变动**（同时显示现值）。
- 班测行的“改正”按钮可修正浓度，状态随新浓度重新判定。
- 旁观账号（viewer）只能打开已钉对照，不能新钉、不能改正。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 顶栏进入 **通风对照**，本机班测选东翼-12、参照主键填回风巷的主键（2）、填通风间隔分钟后钉对照，记下差的绝对值（1.05）。
5. 回班测列表改正其中一笔浓度，重开该对照：差不变，页面出现“来源已变动”。
6. viewer 登录只能打开已钉对照，没有钉定表单与改正按钮。
