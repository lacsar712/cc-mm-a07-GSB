# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 通风对照

检查员可把一条本机班测与另一条按主键（ID）引入的参照班测钉成通风前后对照，钉定时填写通风间隔分钟。服务端存档两笔浓度与状态，并算出浓度差绝对值。顶栏入口为「通风对照」。

存档后任一来源行被改正，对照页仍显示钉定时的浓度差，并标注「来源已变动」。viewer 只能打开已钉对照，不能新钉或改正。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 在「通风对照」里用东翼-12 与回风巷钉一条，记下浓度差绝对值（1.05%）。
5. 在班测页改正其中一笔浓度后重开对照：差仍为 1.05%，且该笔出现「来源已变动」。
6. viewer 登录「通风对照」能看到已钉对照，但没有钉定表单。
